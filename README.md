# Компьютерный клуб "Лимбо"

Система управления бронированиями для компьютерного клуба.

## 🚀 Структура проекта

- `index.html` - Главная страница (лендинг)
- `booking.html` - Форма бронирования
- `admin.html` - Админ-панель
- `start.html` - Стартовая страница с навигацией

## 📦 Файлы стилей

- `styles.css` - Стили главной страницы
- `booking-styles.css` - Стили формы бронирования
- `admin-styles.css` - Стили админ-панели

## 📜 JavaScript

- `script.js` - Логика главной страницы
- `booking-script.js` - Логика бронирования
- `admin-script.js` - Логика админ-панели

## 🌐 Деплой на Netlify

### Вариант 1: Через веб-интерфейс (самый простой)

1. Зайдите на [netlify.com](https://netlify.com) и войдите в аккаунт
2. Нажмите "Add new site" → "Deploy manually"
3. Перетащите папку `C:\Users\PC\Desktop\лимбо` в окно браузера
4. Готово! Ваш сайт будет доступен по адресу типа `https://random-name.netlify.app`

### Вариант 2: Через Netlify CLI

```bash
# Установка Netlify CLI
npm install -g netlify-cli

# Логин в Netlify
netlify login

# Деплой сайта
cd "C:\Users\PC\Desktop\лимбо"
netlify deploy --prod
```

### Вариант 3: Через Git + GitHub

1. Создайте репозиторий на GitHub
2. Загрузите файлы в репозиторий
3. Подключите репозиторий к Netlify
4. Автоматический деплой при каждом коммите
